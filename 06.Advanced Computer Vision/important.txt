Two-Stage Detectors (R-CNN → Faster R-CNN)
The Core Problem Before Modern Detectors

A normal CNN classifier does this:
Image
  ↓
CNN
  ↓
Class

Example:

Image → Dog

But detection requires:

Image
  ↓
Where are objects?
  ↓
What are objects?
The question becomes:
How do we find possible object locations?
This led to the idea of region proposals.

Two-Stage Detection Idea

The name tells you the concept.

Stage 1

Find possible object regions.

Question:

"Where could objects exist?"

Stage 2

Classify those regions.

Question:

"What is inside each region?"

Pipeline:

Image

 ↓

Region Proposal

 ↓

Classification + Box Refinement

 ↓

Final Detection

R-CNN (Region-based CNN)

The original R-CNN introduced this idea.

Step 1 — Generate Regions

An algorithm proposes thousands of possible boxes.

Example:

Image

+----------------+
|                |
|  Box 1         |
|     +----+     |
|     |    |     |
|     +----+     |
|                |
|  Box 2         |
|       +----+   |
|       |    |   |
|       +----+   |
+----------------+

These are called:

Region Proposals

Step 2 — Run CNN on Each Region

Each proposed box is:

Region
   ↓
CNN
   ↓
Feature Vector

Example:

Region 1 → Dog probability
Region 2 → Car probability
Region 3 → Person probability
Step 3 — Predict Box Adjustment

The model improves the box location.

Example:

Initial proposal:

+----------+
|          |
|   Dog    |
|          |
+----------+

Prediction:

 +------+
 | Dog  |
 +------+

Better alignment.

Problem with R-CNN

R-CNN works, but it is extremely slow.

Why?

Because every region goes through the CNN separately.

Example:

2000 regions

2000 CNN passes

Very expensive.


#Fast R-CNN

The improvement:

Instead of running CNN 2000 times:

Run CNN once.

Image
 |
 CNN
 |
Feature Map

Then extract features for each region.

Concept:

Image
 |
Backbone CNN
 |
Feature Map
 |
Region Features
 |
Classifier

Much faster.

This created one-stage detectors.

2. One-Stage Detector Idea

Instead of:

"Find possible objects first, then classify them"

One-stage detectors directly predict:

"Where are objects and what are they?"

Pipeline:

Image

 ↓

Backbone

 ↓

Feature Maps

 ↓

Detection Head

 ↓

Boxes + Classes + Confidence

No region proposal step.

SSD (Single Shot Detector)

SSD was one of the first successful one-stage detectors.

The main idea:

Predict objects at different locations and different scales.
RetinaNet

RetinaNet solved an important problem.

The Problem: Class Imbalance

In an image:

Most locations are background.

Example:

Image pixels:

Background:
████████████████████

Objects:
██

The detector sees millions of negative examples.

This makes training difficult.

6. Focal Loss

RetinaNet introduced Focal Loss.

Idea:

Give more importance to difficult examples.

Normal loss:

Easy examples dominate.

Focal loss:

Hard examples get more attention.

Example:

Easy:

Background confidence = 99%

Ignore more

Hard:

Small object confidence = 40%

Focus training here

This improved one-stage detector accuracy significantly.

ypes of Segmentation

There are three important types.

A. Semantic Segmentation

Every pixel gets a class.

Example:

Road scene:

sky      → blue
road     → gray
car      → red
person   → green

Important:

Two cars have the same label.

Example:

Car 1
Car 2

Both:

class = car

They are not separated.

B. Instance Segmentation

Separates individual objects.

Example:

Semantic:

car car car

Instance:

car-1
car-2
car-3

Each object gets its own mask.

Used in:

robotics
autonomous driving
counting objects
C. Panoptic Segmentation

Combination:

Semantic + Instance.

Example:

Road → semantic

Car1 → instance

Car2 → instance

Person1 → instance

It gives complete scene understanding.

1. The Main Challenge of Segmentation

A classification CNN does:

Image
  ↓
CNN
  ↓
Class

Example:

Dog

But segmentation needs:

Image
  ↓
CNN
  ↓
Pixel prediction
  ↓
Mask

The problem:

CNNs reduce image size.

Example:

Input:

512 × 512

After CNN layers:

32 × 32 feature map

We lose spatial details.

A segmentation model must:

Understand objects
Recover exact pixel locations

This creates the need for special architectures.

2. FCN (Fully Convolutional Network)

FCN was one of the first deep learning segmentation models.

The main idea:

Replace fully connected layers with convolution layers.

Normal CNN:

Image

↓

Convolution

↓

Fully Connected

↓

Class

FCN:

Image

↓

Convolution

↓

Feature Map

↓

Segmentation Mask
How FCN Creates Masks

CNN produces low-resolution features:

Example:

Original:

512×512


Feature:

32×32

FCN uses:

Upsampling

to recover size.

32×32

↓

64×64

↓

128×128

↓

512×512

Final output:

Pixel labels
Problem with FCN

The output is blurry.

Why?

Because:

deep layers understand objects
shallow layers contain details

FCN does not combine them well.

This led to U-Net.

3. U-Net

U-Net is one of the most important segmentation architectures.

Especially in:

medical imaging
satellite images
scientific images

The name comes from its shape:

Encoder          Decoder


    ↓              ↑

     ↓          ↑

       ↓      ↑

          ↓

Looks like:

        U
U-Net Architecture
Encoder

The left side.

Purpose:

Extract features.

Example:

Input:

MRI image

Encoder learns:

edges
textures
shapes
Decoder

The right side.

Purpose:

Recover spatial information.

Produces:

Segmentation mask
The Key Idea: Skip Connections

This is what makes U-Net powerful.

Problem:

Encoder loses details.

Solution:

Copy early features directly to decoder.

Example:

Encoder Feature
      |
      |
      ↓

Decoder Feature

The decoder receives:

High-level information
"this is a tumor"
Low-level information
exact boundary

Example:

Without skip connection:

Tumor detected
but boundary is poor

With skip connection:

Tumor detected
and boundary is accurate
Why U-Net Is Still Popular

Because it works extremely well with limited data.

Medical datasets often have:

few images
expensive annotations

U-Net performs well in these situations.
